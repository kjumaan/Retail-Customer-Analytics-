# Retail Customer Analytics | Python, SQL & Power BI

## 📌 Project Overview
This project focuses on analyzing retail customer shopping behavior to identify purchasing patterns, customer preferences, and business opportunities. The goal is to transform raw data into meaningful insights that can support data-driven business decisions.

## 🎯 Objectives
- Clean and prepare the dataset for analysis.
- Perform Exploratory Data Analysis (EDA) using Python and Pandas.
- Use SQL to answer business questions and identify trends.
- Build an interactive Power BI dashboard to visualize key metrics.
- Generate actionable recommendations based on the analysis.

## 🛠️ Tools & Technologies
- **Python:** Data cleaning, manipulation, and exploratory analysis
- **Pandas & NumPy:** Data processing and analysis
- **SQL / MySQL:** Data querying and business analysis
- **Power BI:** Interactive dashboards and data visualization
- **Jupyter Notebook:** Python development and analysis
- **GitHub:** Project documentation and version control

## 📂 Project Structure
- `data/` — Dataset and data documentation
- `notebooks/` — Python analysis and EDA
- `sql/` — SQL queries used to answer business questions
- `powerbi/` — Power BI report and dashboard files
- `images/` — Dashboard screenshots and visualizations

*The folders above represent the planned structure and will be updated to match the final project files.*

## 🔍 Analysis Process
1. **Data Preparation:** Inspect the dataset, identify missing values and duplicates, and prepare the data for analysis.
2. **Exploratory Data Analysis:** Examine customer characteristics, shopping patterns, and purchasing trends using Python.
3. **SQL Analysis:** Query the data to answer relevant business questions and summarize key metrics.
4. **Dashboard Development:** Create an interactive Power BI dashboard to communicate findings.
5. **Insights & Recommendations:** Translate analytical findings into practical business recommendations.

## 📊 Key Business Questions
- What are the major customer purchasing patterns?
- Which product categories perform best?
- How do customer segments differ in their shopping behavior?
- Which factors are associated with higher customer spending?
- What opportunities exist to improve customer engagement and sales?
